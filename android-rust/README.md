# Discord RU Android

Самостоятельное приложение для Android 7.0 и новее (ARM64). Сетевые запросы к Discord API, локальный прокси и перевод выполняет ядро на Rust. Интерфейс приложения использует стандартные компоненты Android.

- **Войти в Discord** открывает страницу Discord для личного аккаунта. Вход и сеанс обрабатывает сама страница. Встроенный Android System WebView требует поддержки обмена сообщениями с сайтом для кнопки перевода.
- **Чаты сервера через бота** открывает нативный список серверов и текстовых каналов, историю сообщений и отправку от имени бота. Создайте бота в Discord Developer Portal, добавьте его на доступный вам сервер с разрешениями View Channels, Read Message History и Send Messages. Включите Message Content Intent для получения текста обычных сообщений. Вставьте токен бота в приложение. Токен остаётся в памяти до закрытия приложения или выхода. У бота есть доступ к тем каналам, на которые ему выданы разрешения. Голос, DM и push-уведомления в нативном режиме пока не поддерживаются.
- **Настройки → Прокси** открывает проверку доступа к Discord и выбор прямого, автоматического локального или внешнего SOCKS5 / HTTP / HTTPS подключения. Автоматический режим не требует адреса внешнего прокси и может помочь при некоторых DNS- и TLS-фильтрах. При блокировке IP потребуется доступный внешний прокси. В веб-режиме прокси для Discord требует поддержки reverse bypass в Android System WebView.
- **Перевести** переводит текст под сообщением через Google Переводчик. Текст отправляется онлайн при нажатии. Языковые модели не скачиваются.

Сборка ARM64 запускается в GitHub Actions по изменениям ветки `android-rust-client`. Для локальной сборки установите JDK 21, Gradle 8.11.1, Android SDK 35, NDK 27.2.12479018 и Rust 1.85.1 с целью `aarch64-linux-android`. Из корня репозитория запустите `gradle -p android-rust :app:assembleRelease`. Без секретов `ANDROID_RUST_KEYSTORE_BASE64` и `ANDROID_RUST_KEYSTORE_PASSWORD` GitHub Actions подписывает APK временным ключом для тестирования.
