# Discord RU Native

Самостоятельный нативный клиент для Android 7.0 и новее (ARM64). Вход, запросы к Discord, локальный прокси и перевод выполняет ядро на Rust. Экраны используют стандартные компоненты Android.

- **Вход** принимает электронную почту или телефон и пароль для одного личного аккаунта. Данные уходят напрямую в Discord по HTTPS. Пароль не сохраняется. Сеанс шифруется ключом Android Keystore. Поддерживаются коды из аутентификатора, SMS и резервные коды, если Discord предложит их для входа.
- **Личные** и **Серверы** открывают переписки и текстовые каналы. Можно читать историю, отправлять текст, открывать ссылки на вложения и переводить сообщения на русский. Открытый чат проверяет наличие новых сообщений каждые 30 секунд, пока приложение в фокусе. Голосовые звонки и push-уведомления пока недоступны.
- **Настройки → Прокси** открывает проверку доступа к Discord и выбор прямого, автоматического локального или внешнего SOCKS5 / HTTP / HTTPS подключения. Автоматический режим может помочь при некоторых DNS- и TLS-фильтрах. При блокировке IP требуется доступный внешний прокси.
- **Перевести** отправляет выбранный текст в Google Переводчик по нажатию кнопки под сообщением. Языковые модели не скачиваются.

Клиент использует внутренний API Discord. При запросе CAPTCHA, ключа доступа или дополнительной проверки, которую приложение не поддерживает, вход останавливается. Discord может изменить ответы API независимо от версии клиента.

Сборка ARM64 запускается в GitHub Actions по изменениям ветки `android-rust-client`. Для локальной сборки установите JDK 21, Gradle 8.11.1, Android SDK 35, NDK 27.2.12479018 и Rust 1.85.1 с целью `aarch64-linux-android`. Из корня репозитория запустите `gradle -p android-rust :app:assembleRelease`. Без секретов `ANDROID_RUST_KEYSTORE_BASE64` и `ANDROID_RUST_KEYSTORE_PASSWORD` GitHub Actions подписывает APK временным ключом для тестирования.
