# Discord RU для Android

Модификация Discord 355.10, сборка 355010. APK рассчитан на телефоны с ARM64 и Android 7.0 или новее. Root и отдельное приложение для прокси не требуются.

## Установка и перевод

1. Подпись APK отличается от подписи Google Play. Если официальный Discord уже установлен, Android потребует удалить его перед установкой мода. Это удалит вход и локальные данные приложения с телефона. Убедитесь, что у вас есть доступ к аккаунту и двухфакторной аутентификации.
2. Откройте APK и, если Android запросит, разрешите установку из приложения, которым вы открыли файл.
3. Нажмите «Перевести» под текстом сообщения. Перевод появится под ним. Кнопка «Скрыть перевод» сворачивает результат.
4. Для перевода нужен интернет. По умолчанию кнопка отправляет текст в Google Переводчик. Можно выбрать HTTPS-сервер LibreTranslate в настройке «Сервер перевода» во вкладке «Прокси». Языковые модели на телефон не скачиваются.

## Прокси

Локальный HTTP CONNECT-прокси запускается автоматически с Discord и слушает только `127.0.0.1`. Кнопка «Прокси» у правого края открывает отдельную вкладку. На ней можно включить или выключить прокси, сохранить внешний сервер и проверить доступ к Discord. Прокси обслуживает HTTPS и WebSocket к доменам Discord через сетевой клиент приложения. Голос и видео по UDP идут обычным маршрутом, если их использует Discord.

Если поле адреса пустое, локальный прокси открывает соединения через сеть телефона. Он запрашивает адреса Discord через защищённый DNS Cloudflare с запасным системным DNS и разделяет первое TLS-сообщение на записи. Это может помочь при блокировке по DNS или имени сервера. При блокировке самих IP-адресов укажите доступный SOCKS5, HTTP CONNECT или HTTPS CONNECT-прокси. На вкладке «Прокси» выберите протокол, заполните адрес и порт, при необходимости введите имя и пароль, затем нажмите «Сохранить». Адрес `127.0.0.1` подключает к другому прокси, уже запущенному на телефоне. Перезапустите Discord, чтобы переподключить уже открытые соединения. Для HTTPS CONNECT и сервера перевода нужен сертификат публичного центра сертификации. Имя сервера должно совпадать с сертификатом. MTProto предназначен для Telegram.

### Свой внешний сервер

В папке `tools` есть скрипт для Linux-сервера с Python 3.11+. Понадобятся сервер, с которого открывается Discord, доступный для телефона TCP-порт и привязанный к домену TLS-сертификат с полной цепочкой. Запустите на сервере следующую команду и введите пароль в приглашении.

```bash
python3 tools/https-relay.py --port 8443 --user discord \
  --cert /path/to/fullchain.pem --key /path/to/privkey.pem
```

В приложении укажите адрес вида `proxy.example.org:8443` и те же данные входа. Скрипт принимает только CONNECT к разрешённым доменам Discord на порту 443.

## Сборка

Для сборки под Linux x86-64 нужны Rust 1.85.1 с целевым профилем aarch64-linux-android, NDK 27.2.12479018, JDK 17+, Gradle 8.11.1, Python 3, Android SDK с платформой 35 и Build Tools 35.0.0, а также [APKEditor 1.4.9](https://github.com/REAndroid/APKEditor/releases/tag/V1.4.9). Укажите `ANDROID_HOME` и, если Gradle отсутствует в PATH, `GRADLE_BIN`.

Подготовьте каталог с исходными APK Discord 355010. Для ARM64 нужны базовый пакет, библиотечный пакет ARM64 и пакеты плотности и языка. Сборка использовалась с `base.apk`, `config.arm64_v8a.apk`, `config.xxhdpi.apk` и `config.en.apk`.

```bash
tools/build-apk.sh ./discord-splits ./APKEditor-1.4.9.jar ./discordru.p12 ./Discord-RU.apk
```

При первой сборке скрипт предложит создать ключ. Храните его для будущих обновлений этого APK.

## Проверка

Проверены сборка, подпись и выравнивание APK. Тест локального прокси проверяет прохождение трафика через SOCKS5 с паролем. Запуск Discord и доступ к серверу перевода на физическом Android-устройстве пока не проверены.
