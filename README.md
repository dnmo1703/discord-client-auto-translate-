# DC Proxy

Неофициальный клиент Discord для Android: веб-версия discord.com в отдельном приложении с

- **встроенным VLESS-прокси** (ядро xray из [AndroidLibXrayLite](https://github.com/2dust/AndroidLibXrayLite)) — работает только для этого приложения, без системного VPN;
- **переводом сообщений по нажатию** — кнопка «🌐 Перевести» под сообщениями не на русском (Google Переводчик).

## Установка
Скачайте `DCProxy.apk` со страницы **Releases → latest** и установите.

## Настройка
1. Нажмите полупрозрачную кнопку ⚙ справа (её можно перетаскивать).
2. Вставьте ключ `vless://…` → «Проверить» → «Сохранить и переподключиться».
3. Войдите в аккаунт Discord.

Поддерживаются VLESS с TCP / WS / gRPC / XHTTP / HTTPUpgrade, TLS и Reality.

## Ограничения
- Голосовые каналы через прокси не работают (голос идёт по UDP мимо прокси).
- Push-уведомлений нет.
- Сторонние клиенты формально нарушают правила Discord — используйте на свой риск.

## Сборка
GitHub Actions собирает APK при каждом push в `main` (`.github/workflows/build.yml`).
Ключ подписи `app/dcclient.keystore` лежит в репозитории, чтобы обновления ставились поверх, — держите репозиторий приватным.
